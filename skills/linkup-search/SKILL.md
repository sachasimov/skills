# Linkup Search (alias)

This skill has been split into five focused skills. Prefer the one that matches your task:

- **`linkup-web-search`** — the default for any web lookup, research, or question needing current or verifiable information.
- **`linkup-fetch-url`** — when you already know the exact URL and need its content as clean Markdown.
- **`linkup-deep-research`** — for exhaustive, multi-source investigations that can run for minutes.
- **`linkup-bulk-extract`** — to pull many structured records from one known listing page.
- **`linkup-build-workflow`** — to turn a business goal into a multi-step Linkup workflow.

Install the full set with `npx skills add LinkupPlatform/skills`.
